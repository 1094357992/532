# Dataset: Condition monitoring of hydraulic systems (UCI #447)

`condition_monitoring_of_hydraulic_systems.zip` is the original, unmodified archive from the UCI Machine Learning Repository.

- **Source:** https://archive.ics.uci.edu/dataset/447/condition+monitoring+of+hydraulic+systems
- **Citation:** N. Helwig, E. Pignanelli, and A. Schütze. *Condition monitoring of hydraulic systems* [Dataset]. UCI Machine Learning Repository, 2015. https://doi.org/10.24432/C5CW21
- **License:** CC BY 4.0 (redistributed here with attribution, unchanged)
- **Integrity:** the archive's SHA-256 and the hash of every file inside it are listed in `manifest.json`.

Unzip into `data/raw/` to get 17 sensor files (2,205 cycles each, 1/10/100 Hz), `profile.txt` (condition labels and stable flag), and two documentation files.
